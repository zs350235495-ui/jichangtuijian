Clash Verge Rev

Windows macOS Linux

免费开源

目前最主流的 Clash 系桌面客户端，基于 Mihomo（Clash Meta）内核，界面清爽、订阅一键导入，内置延迟测速和规则分组管理。新手和老用户都适合，是 Windows / macOS / Linux 三个平台的首选。

前往 GitHub →

v2rayN

Windows macOS Linux

免费开源

老牌客户端，同时支持 Xray、sing-box 等多种内核和协议，界面偏工具化、配置项更细。适合喜欢自己调参数、或者机场订阅本身是 v2ray / vmess 格式的用户。

前往 GitHub →

Clash Meta for Android

Android

免费开源

Mihomo（Clash Meta）内核在安卓上的官方图形客户端，直接支持机场的 Clash 格式订阅链接，规则分流和测速功能齐全，是安卓上最常见的机场客户端选择。

前往 GitHub →

FlClash

Android Windows macOS Linux

免费开源

同样基于 Mihomo（Clash Meta）内核的新一代客户端，界面走 Material You 风格，比官方客户端更现代，安卓、Windows、macOS、Linux 四端通用，支持 WebDAV 同步配置。想要更好看界面、又不想多设备换不同客户端的话可以试试。注意认准 chen08209/FlClash 这个仓库，网上有同名的仿冒仓库。

前往 GitHub →

v2rayNG

Android

免费开源

和 v2rayN 同一个作者的安卓版本，界面简单直接，支持 Xray 和 v2fly 内核。适合只想快速导入订阅、不需要复杂规则配置的用户。

前往 GitHub →

Shadowrocket（小火箭）

iOS

付费

iOS 上使用人数最多的客户端，圈内俗称「小火箭」，界面简洁、上手快，支持规则分流，是大多数机场教程默认演示用的客户端，新手可以优先考虑它。

前往 App Store →

Nextin（星拓）

iOS macOS

免费

基于 Mihomo（Clash Meta）内核开发的新兴 iOS 客户端，支持 VLESS Reality、Hysteria2、TUIC 等新一代协议，也兼容 Shadowrocket 格式的订阅链接，从小火箭迁移比较省心。不少机场已经开始把它作为默认推荐客户端，但需要用非中国大陆地区的 Apple ID 才能在 App Store 搜到并下载。

前往 App Store →

Stash

iOS macOS

付费

同时支持 iOS 和 macOS，界面设计更贴近苹果原生风格，兼容 Clash 格式订阅。适合已经习惯 Clash 规则体系、又想要苹果生态一体化体验的用户。

前往 App Store →

Hiddify

Android iOS Windows macOS Linux

免费开源

支持 sing-box、Xray 等多种内核的跨平台客户端，安卓、iOS、Windows、macOS、Linux 五端通用，兼容 VLESS、Trojan、Hysteria、Reality 等新协议。iOS 版本除了 App Store，官方还提供 IPA 直装包作为备选下载方式；App Store 版本是否需要非中国大陆地区的 Apple ID 暂未确认，建议先按 App Store 搜索试试，搜不到再用 IPA 方式。是这份名单里少有的免费 iOS 选择，更��频率比上面几个客户端慢一些，但仍在持续维护。注意认准 hiddify/hiddify-app 这个仓库，网上有多个同名仿冒仓库。
