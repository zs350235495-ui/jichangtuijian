家庭与办公室软路由翻墙全攻略：OpenWrt、iStoreOS 配合 OpenClash 透明网关实战

#软路由 #OpenWrt #OpenClash #旁路由 #透明网关 #AppleTV
核心摘要：本文系统讲透软路由硬件选型、iStoreOS 部署、单网口旁路由拓扑接线，以及 OpenClash 内核与 Fake-IP 模式的深度调优，实现局域网所有设备无感高速出海。

一、为什么软路由是全屋透明代理的终极解法

在传统科学上网方案中，我们通常需要在手机、平板、笔记本、台式机等每一台设备上单独安装客户端（如 Clash Verge、v2rayN、Shadowrocket），每次开机都要手动连接；更令人头疼的是，家里的 Apple TV、PS5/Xbox/Switch 游戏机、智能电视和扫地机器人 往往根本无法安装第三方代理应用，导致大屏看 4K Netflix、电视安装 YouTube 应用或者游戏联机极度繁琐。

软路由（Soft Router）的核心价值就在于“一次配置，全屋无感”。它将代理客户端直接运行在路由器硬件系统内部，化身为局域网内的“透明网关（Transparent Proxy Gateway）”。只要你的设备连上家里的 WiFi，无论是一台新手机还是朋友带来的笔记本，无需安装任何软件或配置，立刻自动享受国内外智能分流网络。

三、网络拓扑实操：主路由模式 vs 旁路由（网关模式）

对于已有硬路由家庭，强烈推荐“单网口旁路由（旁路网关）模式”，其最大优点是：即便软路由宕机维护，家里的宽带正常上网完全不受任何影响。

旁路由接线与 IP 规划示例：

  • 主路由：IP 设为 192.168.1.1，负责光猫拨号，正常开启 DHCP 服务，向设备分配 IP。
  • 软路由：仅需一根网线插入 LAN 口，静态 IP 设为 192.168.1.2；在软路由设置中将网关指向主路由 192.168.1.1，DNS 也设为 192.168.1.1。关闭软路由的 DHCP 功能。
  • 终端设备指定科学上网：想要科学上网的设备（如电视机或电脑），只需将网卡设置里的“默认网关”和“DNS”手动修改为 192.168.1.2 即可；不想走软路由的老人家里设备保持自动获取，完全不受干扰。

四、OpenClash 核心插件配置与 Meta 内核调优

在 iStoreOS 或 OpenWrt 的后台服务中，找到 OpenClash 插件：

  1. 进入「插件设置」 → 「版本更新」，将运行内核切换为最新的 Mihomo (Meta) 内核，获得对 Hysteria 2 与 VLESS 的原生硬件加速支持。
  2. 进入「配置文件订阅」，填入你的机场订阅 URL，保存并配置定时自动更新（建议每天凌晨 4 点自动更新）。
  3. 在「常规设置」中勾选「启动自动代理」并保存应用。

五、Fake-IP 与 Redir-Host 模式避坑与 DNS 防劫持

这是软路由最容易踩坑的技术分水岭：

推荐选择「Fake-IP 模式」： 在此模式下，软路由收到客户端的海外域名解析请求时，并不真正向远端发起漫长的 DNS 查询，而是瞬间返回一个虚拟保留 IP 段（198.18.0.1/16）。真正的域名解析被延迟到海外节点本地执行。这彻底消除了国内 DNS 污染，同时将网页首屏打开时间压缩到极致。

六、局域网设备按需精准分流配置

OpenClash 支持针对内网单个 IP 或 MAC 地址进行精准规则控制。在 OpenClash「访问控制」中：

  • 电视盒子（Apple TV）：设为指定策略组，强制锁定在原生流媒体全解锁专线节点。
  • 国内智能家居设备：加入白名单，强制走 DIRECT 直连，避免米家、扫地机器人产生莫名断连或报错。

七、软路由最常见两大硬件网络故障：网关回环与 ARP 广播风暴排查

很多新手在配置单网口旁路由时，经常遇到“刚一插上网线，全家网络立刻瘫痪，微信电脑同时掉线”的灾难级故障。这主要是由DHCP 冲突与网关回环引起的：

  • DHCP 双服务器冲突：如果你的主路由器开着 DHCP，而软路由刷完固件后默认也开着 DHCP 服务，两个路由器在局域网内会疯狂争夺 IP 分配权，导致电脑获取到错误的网关地址。解决办法：坚决关闭软路由的“忽略此接口”以外的所有 DHCP 相关服务。
  • 防火墙数据包伪装（IP 动态伪装）：在 OpenWrt 网络 → 防火墙 → 自定义规则中，必须添加如下 iptables 规则，否则部分硬路由在收到旁路由转发的数据包时会将其当作局域网非法数据丢弃：
    iptables -t nat -I POSTROUTING -o eth0 -j MASQUERADE

八、主机党福音：优化 PS5 / Switch / Xbox 全球联机 NAT 类型

在默认情况下，很多家庭网络在连入主机时被判定为 NAT Type 3 (严格 / NAT-D)，导致《怪物猎人》、《喷射战士》、《使命召唤》根本无法与好友组队或进房间。

软路由一键优化 NAT-B / NAT-A 秘笈：

  1. 在 OpenClash 设置中勾选「UDP 转发 (UDP Proxy)」与「FullCone NAT」支持；
  2. 在策略组中，将任天堂（Nintendo）与索尼（PlayStation）的分流规则指定走具备电竞专线加速能力的节点（如闪电鼠、神行加速）；
  3. 在主路由光猫处开启 UPnP 功能。此时打开 Switch 测试连接，NAT 类型将立刻跳升至 NAT Type B，联机组队秒排进房。
